# 扎烦恼 · 日常烦恼仪式 Demo

面向打工人的像素风轻解压 Demo：认领今天的烦恼，把它扎小，再收进一周档案。

- 在线试玩：**https://yizong2-cloud.github.io/zhafannao/**
- 三类烦恼：工作量、等回复、模糊疲惫
- 玩法：认领烦恼 → 点击 12 次 → 缩小转化 → 退场怪话 → 七日档案/脱敏共鸣卡
- 页面底部可以切换 A「仪式优先」、B「档案优先」、C「传播优先」三个结构版本
- 支持手机浏览器与微信内打开；Demo 不上传个人输入

> v0.7.1 一次性 HTML Canvas 比较原型；正式版仍计划使用 Cocos Creator。
